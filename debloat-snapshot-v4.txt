## Learnings (DO NOT repeat):
# - pm install -r /system/priv-app/X.apk → installs to /data/app/ as UPDATED_SYSTEM_APP, LOSES privileged permissions
# - pm uninstall com.android.systemui (no -k --user 0) → removes update, reverts to system copy
# - pm clear com.android.systemui → corrupts keyguard → black screen lockout
# - SystemUI CANNOT be removed — required for system-wide navigation
# - immersive.full=* hides nav bar in ALL apps → user gets stuck in Settings
# - force-stop SystemUI → LMK kills Termux and bot
